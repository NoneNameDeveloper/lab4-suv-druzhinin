# Описание учебного проекта

В ходе лабораторной работы проверяется обмен изменениями между локальным и удалённым репозиториями Git.

## Выполняемые операции

1. Клонирование репозитория командой `git clone`.
2. Создание локального коммита и публикация через `git push`.
3. Получение обновлений с помощью `git fetch` и `git pull`.
4. Разработка в отдельной ветке и передача изменений через Pull Request.
5. Проверка содержимого коммита перед слиянием.

Проект не требует внешних зависимостей: для запуска нужен Python 3.
